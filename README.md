A compact alpha-beta chess engine in 4 KB of Python that plays the make.fun house gauntlet: negamax with principal-variation search, quiescence, a transposition table, killer moves and a history heuristic, searching to a fixed node budget per move.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
